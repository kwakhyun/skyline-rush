# SKYLINE RUSH — 특별 구간 / Rules 7

## 구현 범위

매 3,000m 주기의 다섯 테마에 144m 길이 특별 구간을 배치한다.

| 테마 | 시작 거리 | 3D 랜드마크 |
|---|---:|---|
| 자연숲 | 360m | 뿌리와 가지가 연결된 거목 아치 |
| 도심 | 864m | 리벳 강재, 대각 버팀대, 공사 스카이브리지 |
| 아트리움 | 1,368m | 대리석 기둥과 프리즘 보안 게이트 |
| 정글 | 1,728m | 이끼 낀 석조 아치와 층층이 쌓은 교각 |
| 차원 | 2,712m | 두 겹의 다각 에너지 관문과 흑요석 기둥 |

이미지 콘셉트 화면이 아니라 게임의 월드 좌표에 배치하는 실제 메시다. `HOORunner::Frame`을 사용해 경사와 코너에 맞춰 회전한다. 80개 타일의 고정 인스턴스 풀을 재활용한다. 주변 구조물은 게임 차선 밖에 두며, 천장·광선으로 캐릭터나 장애물을 가리지 않는다.

## 위험과 보상

- 첫 36m는 안내 구간. 이후 36m 간격으로 점프 장애물, 슬라이드 장애물, 한 차선 틈을 배치한다.
- 청록색 중앙 차선은 전체 구간에서 열려 있다. 금색 도전 차선은 시드와 구간에 따라 좌우가 결정된다.
- 도전 장애물 안에 들어갔다가 전체 충돌 범위를 지나 뒤쪽 금색 결정에 닿으면 수집 20점 + 위험 보상 80점에 현재 배율을 적용하고 피버 충전 3을 얻는다.
- 충돌, 피버 무적, 피격 후 보호, 자동 비행을 이용한 통과는 추가 보상을 주지 않는다.
- 피버 자석은 기본 결정에만 적용한다. 위험 보상은 직접 도전해야 한다.

## 아슬아슬 판정

장애물 옆 충돌 경계에서 48cm 이내로 스치거나, 낮은 점프 여유 높이·종료 직전 슬라이드로 통과하면 40점 × 현재 배율. 충돌 구간에 진입하는 동안 후보를 추적하고 **충돌 범위를 완전히 벗어난 뒤** 확정한다. 같은 행에서 한 번만 지급하며, 피격과 보호 상태는 후보를 무효화한다. 네 개의 행 샘플만 순환 사용한다.

## 점수와 저장

총점 = 거리 점수 + 수집 점수 + 위험 보상 + 아슬아슬 점수. 종료·일시정지 화면에 네 항목과 도전/정밀 회피 횟수를 표시하고 로컬 기록에도 저장한다.

규칙 변경으로 온라인 검증은 Rules 7, 보드는 `main-v7`/`qa-v7`, 로컬 저장은 `SkylineRush_Record_v6`으로 분리한다. 이전 저장 파일은 삭제하지 않으며 이전 점수를 새 시즌에 합산하지 않는다. 음악·음량·그래픽 설정과 플레이어 인증은 기존 설정을 유지한다.

## 이미지와 제작

`SourceArt/Environment/SpecialSections/T_SpecialSurfaces_v1.png`는 내장 Imagegen으로 새로 만든 3×2 표면 아틀라스다. 원본을 그대로 보관하며 Unreal 재질의 UV 범위로 각 표면을 선택한다. 거목/강철/대리석/비취/차원 세라믹 표면에 거칠기와 금속성, 명암 기반 셰이더 표면 요철을 적용한다. 5개 관문 메시는 `Tools/Unreal/build_special_sections.py`의 원본 기하로 생성한다. 외부 게임의 레벨이나 소품을 복사하지 않았다.

각 이미지 셀은 512×512이며 고해상도 실사 스캔을 대신하는 자산은 아니다. 접사보다 빠른 3인칭 주행에서의 재질 차이와 공간 입체감을 목표로 한다.
