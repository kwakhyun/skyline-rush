# 현재 게임 규칙

SKYLINE RUSH는 자동 전진하는 3인칭 무한 러너입니다. 세 레인 이동, 점프, 시간 제한 슬라이드를 사용합니다. 거리와 함께 속도·코스 난이도가 증가합니다. 목숨 3개, 장애물 충돌 피드백, 수집 아이템, 부스터, 피버, 발사 타일과 비행 전환을 유지합니다.

시각 테마는 3,000m 주기로 자연숲(0–600m), 도심(600–1,260m), 건물 내부(1,260–1,660m), 정글(1,660–2,060m), 차원 공간(2,060–3,000m)으로 전환됩니다. 시각 테마와 경사·회전·점프 등 코스 물리 테마는 별개입니다.

C++ 고정 스텝 시뮬레이션과 시드로 코스·충돌을 결정합니다. 장애물의 시각 위치와 충돌은 같은 타일 정의를 사용합니다. 온라인 서버는 규칙 버전 6 리플레이를 재현해 점수를 검증합니다. 정리 작업에서는 규칙·입력·리플레이 형식을 바꾸지 않았습니다.

기록 저장 슬롯은 SkylineRush_Record_v5이며 이전 기록 마이그레이션을 유지합니다. QA는 별도 슬롯을 사용합니다. 포커스를 잃으면 일시정지하고 사용자가 직접 재개합니다.
