# 현재 게임 규칙

SKYLINE RUSH는 자동 전진하는 3인칭 무한 러너입니다. 세 레인 이동, 점프, 시간 제한 슬라이드를 사용합니다. 거리와 함께 속도·코스 난이도가 증가합니다. 목숨 3개, 장애물 충돌 피드백, 수집 아이템, 부스터, 피버, 발사 타일과 비행 전환을 유지합니다.

시각 테마는 3,000m 주기로 자연숲(0–600m), 도심(600–1,260m), 건물 내부(1,260–1,660m), 정글(1,660–2,060m), 차원 공간(2,060–3,000m)으로 전환됩니다. 시각 테마와 경사·회전·점프 등 코스 물리 테마는 별개입니다.

C++ 고정 스텝 시뮬레이션과 시드로 코스·충돌을 결정합니다. 장애물의 시각 위치와 충돌은 같은 타일 정의를 사용합니다. 온라인 서버는 규칙 버전 7 리플레이를 재현해 점수를 검증합니다. 이전 버전 6 게임은 별도 시즌에서 계속 사용할 수 있습니다.

기록 저장 슬롯은 SkylineRush_Record_v6입니다. 새 점수 규칙으로 시즌을 분리하며 이전 슬롯은 삭제하지 않습니다. QA는 별도 슬롯을 사용합니다. 포커스를 잃으면 일시정지하고 사용자가 직접 재개합니다.

다섯 테마마다 144m 특별 구간이 있습니다. 청록색 중앙은 안전 경로, 금색 좌우 차선은 점프·슬라이드·틈 통과의 추가 보상 경로입니다. 정밀 회피는 아슬아슬 점수를 주며, 결과 화면은 거리·수집·위험 보상·아슬아슬 점수를 나눠 표시합니다. 배치와 점수의 세부 규칙은 [SPECIAL_SECTIONS.md](SPECIAL_SECTIONS.md)를 참고하세요.

배경음악은 Breezy Adventure 첫 번째 곡(179.88초), 두 번째 곡(178.72초) 순서로 계속 교대합니다. 시작 화면과 결과 화면에서도 이어지고 재도전·새 코스 선택으로 곡을 재시작하지 않습니다. 플레이 일시정지 시 음악도 멈추고 재개하면 같은 위치에서 이어집니다. 기존 소리 크기 설정을 따르며 효과음이 들리도록 음악에는 별도 45% 기본 게인을 적용합니다.

수집·피격·부스터·피버는 각각 별도 효과음을 사용합니다. 수집음은 0.35초이고 최대 두 개까지 겹치며, 새 소리가 초과하면 오래된 소리를 30ms에 걸쳐 줄입니다. 피격은 0.95초, 부스터는 1.4초, 피버는 1.8초입니다. 부스터·피버가 발동한 프레임에는 일반 수집음을 생략해 중요한 신호를 분명하게 합니다. 마지막 피격에서는 피격음이 한 번만 나옵니다. 기존 소리 크기 설정을 따르고 0%에서는 효과음을 재생하지 않습니다.
